# Sobre este projeto
Este é um projeto web feito para mostrar um portfólio e uma jornada do curso de desenvolvimento de jogos da instituição Senac na cidade de São Carlos (unidade CAR).

O projeto deve apresentar uma linha do tempo contando a história e também permitir acessar links de jogos dos alunos, criando uma espécie de portfólio que é atrelado à jornada.

## Tecnologias
- HTML: padrão
- CSS: usar Tailwind na versão mais recente
- JavaScript: usar React na versão mais recente
- Servidor: não há servidor, todo o conteúdo deve ser buildado em HTML estático para ser hospedado em um servidor simples e tradicional que roda PhP (embora não seja usado PhP)

### Código
- Nomeação: toda nomeção do código deve ser em inglês (variáveis, funções, etc)
- Comentários: todos comentários devem ser feitos em português. Além disso, adicione comentários apenas quando for necessário para explicar códigos mais complexos. Códigos simples que podem ser facilmente entendidos apenas olhando não precisam de comentários. Evite poluir o código com comentários
- Clean Architecture: use os conceitos de clean architecture neste projeto. Atrelado aos itens anteriores, use bons nomes de variáveis e funções que permita ser explicado o que o código faz só de lê-los
- Arquitetura geral: use códigos simples. Evite lógicas muito complexas, mesmo que pra isso tenha que criar mais funções. Imagine que o código deve ser lido e entendido por um Junior com pouca experiência

## Páginas
Este site deve ter três páginas:
- Página inicial (timeline): a página inicial deve ser também a página da timeline que mostra a linha do tempo do curso, onde mostra sua jornada de forma organizada.
- Jogos dos Alunos: uma página onde deve mostrar todos nossos alunos e os links para seus jogos
- Jogos do Professores: uma página identica ao dos alunos, porém deve ter uma estrutura visual diferente, onde deve ter o portfólio dos professores
